# Security Policy

## Supported Versions

We actively support and patch the following versions of this project:

| Version | Supported          |
| ------- | ------------------ |
| 0.16     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do **NOT** open a public issue. 

Please report it privately using GitHub's native reporting tool:
1. Click the **Security** tab at the top of this repository.
2. Click the **Report a vulnerability** button to securely submit your findings.

### What to Include:
* A brief description of the bug and its impact.
* Steps or a script to reproduce the issue.

### Our Response
We will review your submission within **48 hours** and aim to coordinate a fix or update within **14 days**. Thank you for helping keep this project secure!
