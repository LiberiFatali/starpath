# Security Policy

## Supported Versions

We actively support and patch the following versions of this project:

| Version | Supported          |
| ------- | ------------------ |
| 0.5     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do **NOT** open a public issue. 

Please report it privately using GitHub's native reporting tool:
1. Navigate to the **Security** tab at the top of this repository.
2. Select **Advisories** from the left sidebar.
3. Click the **Report a vulnerability** button to securely submit your findings to the maintainers.

### What to include:
* A brief description of the bug and its impact.
* Steps or a script to reproduce the issue.

### Our Response
We will acknowledge your report within **48 hours** and aim to provide a fix or update within **14 days**. We appreciate your help in keeping this project secure!
